# 读取数据表接口 V1：

- cmd:load\_data
- dtname:所属数据表
  - 客户表：customer
  - 产品表：product
- field:  指定展示字段，多字段之间用逗号隔开；缺省为：列表中显示的字段
- where: 指定过滤条件。缺省是根据登录人权限显示指定的数据。设置过滤条件后，是在登录人权限的基础上加入新的条件。
  - 标准sql，一个列子
  - 比如用户=M2或U3  and  (2025-12-01>日期>2025-12-14 or type=押金）
  ```sql
  (owner = 'M2' or owner = 'U3') and date between '2025-12-01' and '2025-12-14' or type=2
- limit: 指定限制数量，如指定100，只显示100条数据； 缺省没限制数量。
- start: 指定开始位置，多用于分页。如：第一次从0开始显示100条，第二次从100开始再显示100条，第三次从200开始再显示100条

  ```

JSON样例：

```json
{
	"cmd":"load_data",
	"field":"id,cu_name,m_name,life",
	"where":"life=1",
	"dtname":"customer"
}
```

# 读取数据表接口 V2

## 比如读取客户表：

### 方式1：返回字段函数值
比如枚举类，返回的值是value（VIP客户），而不是key（1）
比如cu_id，返回的是客户名称，而不是客户id
#### 参数说明：
- cmd:load_data
- dtname:所属数据表 customer
- field:  指定展示字段，多字段之间用逗号隔开；缺省为：列表中显示的字段
- where: 指定过滤条件。缺省是根据登录人权限显示指定的数据。设置过滤条件后，是在登录人权限的基础上加入新的条件。
- limit: 指定限制数量，如指定100，只显示100条数据； 缺省没限制数量。
- start: 指定开始位置，多用于分页。如：第一次从0开始显示100条，第二次从100开始再显示100条，第三次从200开始再显示100条

#### JSON样例：
```json
{
	"cmd":"load_data",
	"field":"id,cu_name,m_name,life",
	"where":"life=1",
	"dtname":"customer"
}
```

### 方式2：直接返回数据库中保存的值，在方式1的基础上增加参数：flag=1

#### 参数说明：
- cmd:load_data
- dtname:所属数据表 customer
- field:  指定展示字段，多字段之间用逗号隔开；缺省为：列表中显示的字段
- where: 指定过滤条件。缺省是根据登录人权限显示指定的数据。设置过滤条件后，是在登录人权限的基础上加入新的条件。
- limit: 指定限制数量，如指定100，只显示100条数据； 缺省没限制数量。
- start: 指定开始位置，多用于分页。如：第一次从0开始显示100条，第二次从100开始再显示100条，第三次从200开始再显示100条
- flag: 调用方案标记：flag=1代表方式2，返回数据库中的值

#### JSON样例：
```json
{
	"cmd":"load_data",
	"field":"id,cu_name,m_name,life",
	"where":"life=1",
	"dtname":"customer",
	"flag":1,
	"start":20,
	"limit":10
}
```

测试路径：https://dev211.x2crm.cn/0/api/load_data_customer.html

# 读数据表中获取count
## 调用例子
说明："field": "count(1) cnt" 用于计数，cnt是返回值的key
```json
{
  "cmd": "load_data",
  "field": "count(1) cnt",
  "where": "life=1",
  "dtname": "customer",
  "flag": 1
}
```

## 返回值例子
说明：根据上面调用计数参数的key，返回值的key是cnt，数量是12876
