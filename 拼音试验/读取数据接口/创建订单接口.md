# 创建订单 - 数据接口文档

## 接口基础信息

- **接口路径**: `/system/api.xt`
- **请求方式**: POST
- **Content-Type**: `application/json`
- **通用返回格式**:
```json
{
  "ok": 1,        // 1=成功, 0=失败
  "msg": "提示信息",
  "data": {}      // 业务数据
}
```

---

## 创建订单接口

### 接口说明

通过此接口可以创建订单（主表contract）及其产品明细（子表goods），支持批量创建多条订单数据。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cmd | string | 是 | 固定值: `create_data` |
| dtname | string | 是 | 固定值: `contract_api` |
| required_skip | int | 否 | 是否跳过必填校验, 0=不跳过(默认), 1=跳过 |
| list | string | 是 | 订单数据数组(JSON字符串) |

### 请求示例

```json
{
  "cmd": "create_data",
  "dtname": "contract_api",
  "required_skip": 0,
  "list": "[{\"number\":\"\",\"subject\":\"测试接口导入订单\",\"cu_id\":\"梦蝶北京\",\"who\":\"刘琪峰\",\"date\":\"2026-06-03\",\"end_date\":\"2026-07-03\",\"sum\":50000,\"status\":\"执行中\",\"memo\":\"API接口创建\",\"subdata\":[{\"name\":\"P001\",\"pn\":\"服务器A\",\"pm\":\"X86-100\",\"amount\":5,\"un_price\":8000,\"zk\":\"100%\",\"tax_rate\":13,\"tax_money\":5200,\"sum\":45200}]}]"
}
```

### list 数组中每条数据的字段说明

#### 主表字段（contract）

| 字段 | 中文名 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| number | 订单编号 | string | 否 | 为空时系统自动生成；不可与已有编号重复 |
| subject | 订单主题 | string | 是 | 订单主题 |
| cu_id | 客户 | string | 是 | 客户名称（全称或简称，全称优先） |
| date | 日期 | string | 是 | 签约日期，格式: YYYY-MM-DD |
| end_date | 最晚发货 | string | 否 | 最晚发货日期，格式: YYYY-MM-DD |
| sum | 总金额 | number | 否 | 订单总金额 |
| who | 所有者 | string | 否 | 负责人姓名 |
| status | 状态 | string | 否 | 执行中 / 结束 / 意外中止，三选一 |
| prj_id | 对应项目 | string | 否 | 项目标题、项目号或项目ID |
| memo | 订单备注 | string | 否 | 备注信息 |
| money_type | 币种 | string | 否 | 如: RMB, USD, JPY（开启多币种时有效） |
| money_rate | 汇率 | number | 否 | 汇率值（开启多币种时有效，默认100） |
| back_sum | 已回款 | number | 否 | 回款金额（需有回款管理权限且未开启订单审批） |

> **扩展字段**: 主表还支持通过系统配置的自定义扩展字段（memo_kv中contract_ext配置的字段），字段名以实际配置为准。

#### 子表字段（goods，通过 subdata 传入）

| 字段 | 中文名 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| name | 产品编号 | string | 是 | CRM中的产品编号（编号优先匹配） |
| pn | 品名 | string | 条件 | 产品品名（无编号时，品名+型号匹配，必须唯一） |
| pm | 型号 | string | 条件 | 产品型号（无编号时，品名+型号匹配，必须唯一） |
| amount | 数量 | number | 是 | 订购数量 |
| un_price | 单价 | number | 是 | 产品单价 |
| zk | 折扣 | string | 否 | 百分比格式，如: 100%、90%，范围0~100% |
| tax_rate | 税率 | number | 否 | 税率百分比，如: 13 表示13% |
| tax_money | 税金 | number | 否 | 税金金额 |
| un_price_tax | 含税单价 | number | 否 | 含税单价 |
| sum | 金额 | number | 否 | 金额，为0时系统自动计算: amount*un_price*zk/100+tax_money |
| memo | 产品备注 | string | 否 | 产品明细备注 |

> **产品匹配优先级**: 产品编号(name) > 品名(pn)+型号(pm)。同一订单内产品不可重复。

## 业务规则说明

### 1. 订单编号唯一性
- 订单编号（number）不可与CRM中已有订单重复
- 为空时系统自动生成编号

### 2. 客户名称匹配规则
- 客户名称必须等于CRM中客户名称的**全称或简称**（全称优先匹配）
- 匹配成功后，系统会自动回填客户ID

### 3. 产品匹配规则
- **编号优先**：优先使用产品编号（name字段）匹配
- **品名+型号**：无编号时使用品名(pn)+型号(pm)匹配，必须唯一
- **不可重复**：同一订单内产品不可重复
- 产品必须存在且未删除/停售

### 4. 折扣格式
- 必须使用百分比格式，如 `100%`、`90%`
- 范围: 0%~100%
- 为空时默认 `100%`

### 5. 子表金额自动计算
当子表明细的 `sum` 字段为0或为空时，系统自动按以下公式计算：
```
sum = amount * un_price * zk / 100 + tax_money
```
示例: 单价8000, 数量5, 折扣100%, 税金5200 → sum = 5*8000*100/100+5200 = 45200

### 6. 状态填写规则
- 只能填写以下三种状态之一：`执行中`、`结束`、`意外中止`

### 7. 项目关联
- prj_id 支持传入项目标题、项目号或项目ID
- 匹配不唯一时会报错，建议使用项目号或ID

### 8. 多币种支持
- 开启多币种功能后，需传入 money_type 和 money_rate
- money_type 支持中文或简写（如: 人民币/RMB, 美元/USD）
- 未开启多币种时默认 RMB，汇率100

### 9. 自动回款
- 当传入 back_sum（已回款金额）且金额>0时，系统自动生成回款记录
- 前提条件：当前用户有回款管理权限，且未开启订单审批功能

### 10. 所有者自动设置
- 主表的所有者（owner）由系统自动设置为当前登录用户的部门（part）
- 子表的所有者同样自动设置

### 11. 批量创建
- `list` 数组支持传入多条订单数据
- 每条数据独立处理，互不影响
- 返回结果中会逐条说明成功或失败原因

## JS 调用样例

### 1. 基础调用（创建单条订单）

```javascript
function createContract() {
  const param = {
    cmd: "create_data",
    dtname: "contract_api",
    required_skip: 0,
    list: JSON.stringify([
      {
        number: "",
        subject: "测试接口导入订单",
        cu_id: "梦蝶北京",
        who: "刘琪峰",
        date: "2026-06-03",
        end_date: "2026-07-03",
        sum: 50000,
        status: "执行中",
        memo: "API接口创建",
        subdata: [
          {
            name: "P001",
            pn: "服务器A",
            pm: "X86-100",
            amount: 5,
            un_price: 8000,
            zk: "100%",
            tax_rate: 13,
            tax_money: 5200,
            sum: 45200
          }
        ]
      }
    ])
  };

  fetch('/system/api.xt', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(param)
  })
  .then(res => res.json())
  .then(data => {
    if (data.ok === 1) {
      console.log('创建成功', data);
      alert(data.msg);
    } else {
      console.log('创建失败', data);
      alert(data.msg);
    }
  })
  .catch(error => {
    console.error('请求异常:', error);
  });
}
```

| 0 | 失败（所有数据均创建失败，或参数错误） |

## 常见错误信息

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 未提供参数：dtname | 未传dtname参数 | 传入 dtname: "contract" |
| 参数：list数据解析为JSON出错 | list不是合法JSON | 检查JSON格式 |
| 您没有订单管理权限 | 当前用户无订单权限 | 联系管理员开通权限 |
| 订单编号[xxx]和CRM中id=xx的订单重复 | 订单编号已存在 | 更换编号或留空自动生成 |
| 未找到项目：xxx | 项目不存在 | 检查项目标题/编号/ID |
| 项目：xxx 数据不唯一 | 项目匹配到多条 | 使用项目号或ID |
| 折扣xxx不是百分比 | 折扣格式错误 | 使用百分比格式如 "90%" |
| 折扣xxx必须大于等于0且小于等于100 | 折扣超出范围 | 调整为0~100之间的百分比 |
| xxx + xxx 的产品没找到 | 产品不存在 | 检查品名和型号 |
| xxx + xxx 的产品不唯一 | 品名+型号匹配到多个 | 使用产品编号 |
| 订单内产品重复 | 同一订单中有相同产品 | 去重或合并数量 |
| 无编号为：xxx 的产品或已删除\停售 | 产品编号不存在 | 检查产品编号 |

## 数据处理流程

```
请求 → 参数校验(cmd/dtname/list) → 加载contract数据模型 → 遍历list数组
  → loadAPIParam(字段映射与校验) → checkInputData(业务校验)
    → 权限校验(订单管理权限)
    → 订单编号唯一性检查
    → 项目关联校验
    → 多币种处理
    → 产品匹配(编号优先 > 品名+型号)
    → 折扣格式校验
    → 子表金额自动计算
  → checkFunTurn(字段函数转换)
  → inputData(保存数据)
    → saveMainDb(保存主表contract)
      → addDefaultM(设置默认值: viewtype=1, begin_date=date, pay_mode=-1, type=-1)
    → saveSubDb(保存子表goods，循环每条明细)
      → addDefaultS(子表默认值: status=3)
      → addSpecialS(子表特殊处理: 回填客户ID)
  → afterSave(后续处理)
    → 生成订单明细数据
    → 更新总金额
    → 重算订单状态
    → 写入变更日志
    → 子表币种汇率同步
    → 自动生成回款记录(如有back_sum)
  → endDo(后续处理)
← 返回结果
```
