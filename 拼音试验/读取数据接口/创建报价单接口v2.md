# 创建报价单 - 数据接口文档

## 接口基础信息

- **接口路径**: `/system/api.xt`
- **请求方式**: POST
- **Content-Type**: `application/json`
- **通用返回格式**:
```json
{
  "ok": 1,        // 1=成功, 0=失败
  "msg": "提示信息",
  "data": {}      // 业务数据
}
```

---

## 创建报价单接口

### 接口说明

通过此接口可以创建报价单（主表）及其明细（子表），支持批量创建多条报价单数据。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cmd | string | 是 | 固定值: `create_data` |
| dtname | string | 是 | 固定值: `price` |
| required_skip | int | 否 | 是否跳过必填校验, 0=不跳过(默认), 1=跳过 |
| list | string | 是 | 报价单数据数组(JSON字符串) |

### 请求示例

```json
{
  "cmd": "create_data",
  "dtname": "price",
  "required_skip": 0,
  "list": "[{\"number\":\"\",\"title\":\"测试接口导入11\",\"cu_id\":\"梦蝶北京\",\"who\":\"刘琪峰\",\"date\":\"2026-06-03\",\"type\":\"服务报价\",\"price\":1020,\"A设备材料费\":10,\"j2\":20,\"subdata\":[{\"pro_id\":15537,\"num\":10,\"price\":20,\"tax_rate\":20},{\"pro_id\":4,\"num\":10,\"price\":20,\"money\":200}]}]"
}
```

### list 数组中每条数据的字段说明

#### 主表字段（price）

| 字段 | 中文名 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| number | 报价单号 | string | 否 | 为空时系统自动生成 |
| title | 主题 | string | 是 | 报价单主题 |
| date | 日期 | string | 是 | 格式: YYYY-MM-DD |
| cu_id | 客户 | string | 是 | 客户名称（全称或简称，全称优先） |
| price | 报价（总） | number | 否 | 报价总金额 |
| money_type | 币种 | string | 否 | 如: CNY, USD |
| money_rate | 汇率 | number | 否 | 汇率值 |
| memo | 备注 | string | 否 | 备注信息 |
| op_id | 销售机会 | string | 否 | 关联销售机会 |
| prj_id | 项目 | string | 否 | 关联项目 |
| sname | 报价人 | string | 否 | 报价人姓名 |
| type | 分类 | string | 否 | 报价分类，如: 服务报价 |
| who | 所有者 | string | 否 | 负责人姓名 |

> **扩展字段**: 主表还支持通过系统配置的自定义扩展字段（memo_kv中price_ext配置的字段），字段名以实际配置为准。

#### 子表字段（pricedetail，通过 subdata 传入）

| 字段 | 中文名 | 类型 | 必填 | 说明 |
|------|--------|------|------|------|
| pro_id | 产品 | int | 是 | 产品ID（CRM中的产品编号） |
| num | 数量 | number | 是 | 产品数量 |
| price | 单价 | number | 是 | 产品单价 |
| tax_rate | 税率 | number | 否 | 税率百分比，如: 20 表示20% |
| money | 金额 | number | 否 | 金额，为0时系统自动计算: (1+tax_rate/100)*num*price |

### 返回结果

#### 成功响应

```json
{
  "ok": 1,
  "msg": "数据共：1条；1条成功；0条失败",
  "list": [...],
  "ret": [
    "第1条:创建数据成功"
  ]
}
```

#### 返回list说明
`list` 数组会原样回显在响应中（与请求参数顺序一一对应）。  
每条数据**保存成功后**，系统会把生成的 `id`（及编号等关键字段）写入该对象返回，便于前端直接定位新数据。

**响应示例**：

```json
{
  "ok": 1,
  "msg": "数据共：1条；1条成功；0条失败",
  "list": [
    {
      "number": "",
      "title": "测试对象导入",
      "cu_id": "梦蝶北京",
      "who": "刘琪峰",
      "date": "2026-06-05",
      "type": "服务报价",
      "price": 1020,
      "A设备材料费": 10,
      "j2": 20,
      "subdata": [
        { "pro_id": 15537, "num": 10, "price": 20, "tax_rate": 20 },
        { "pro_id": 4, "num": 10, "price": 20, "money": 200 }
      ],
      "id": 1028
    }
  ],
  "ret": [
    "第1条:创建数据成功"
  ]
}
```

**关键点**：
- `list` 中的对象与请求时一一对应，**顺序不变**。
- 成功时，对象会被**追加一个 `id` 字段**（即新生成的主表ID）。
- 失败时，对象不会被改写，但 `ret` 数组中对应位置会写入错误原因。
- 子表（`subdata`）相关字段（如 `id`）也会一并回填，可在二次确认时直接读取。

#### 部分成功响应

```json
{
  "ok": 1,
  "msg": "数据共：3条；2条成功；1条失败",
  "list": [...],
  "ret": [
    "第1条:创建数据成功",
    "第2条:创建数据失败:客户名称不存在",
    "第3条:创建数据成功"
  ]
}
```

#### 全部失败响应

```json
{
  "ok": 0,
  "msg": "数据共：1条；0条成功；1条失败",
  "list": [...],
  "ret": [
    "第1条:创建数据失败:客户名称不存在"
  ]
}
```

#### 参数错误响应

```json
{
  "ok": 0,
  "msg": "未提供参数：dtname"
}
```

```json
{
  "ok": 0,
  "msg": "参数：list数据解析为JSON出错"
}
```

## 业务规则说明

### 1. 子表金额自动计算
当子表明细的 `money` 字段为0时，系统会自动按以下公式计算：
```
money = (1 + tax_rate / 100) * num * price
```
示例: 单价20, 数量10, 税率20% → money = (1 + 20/100) * 10 * 20 = 240

### 2. 客户名称匹配规则
- 客户名称必须等于CRM中客户名称的**全称或简称**（全称优先匹配）
- 匹配成功后，系统会自动回填客户ID

### 3. 产品匹配规则
- 优先使用 `pro_id`（产品编号）匹配
- 如果有产品编号匹配成功，则忽略品名型号匹配

### 4. 所有者自动设置
- 主表的所有者（owner）由系统自动设置为当前登录用户的部门（part）
- 子表的所有者同样自动设置

### 5. 批量创建
- `list` 数组支持传入多条报价单数据
- 每条数据独立处理，互不影响
- 返回结果中会逐条说明成功或失败原因

## JS 调用样例

### 1. 基础调用（创建单条报价单）

```javascript
function createPrice() {
  const param = {
    cmd: "create_data",
    dtname: "price",
    required_skip: 0,
    list: JSON.stringify([
      {
        number: "",
        title: "测试接口导入11",
        cu_id: "梦蝶北京",
        who: "刘琪峰",
        date: "2026-06-03",
        type: "服务报价",
        price: 1020,
        subdata: [
          {
            pro_id: 15537,
            num: 10,
            price: 20,
            tax_rate: 20
          }
        ]
      }
    ])
  };

  fetch('/system/api.xt', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(param)
  })
  .then(res => res.json())
  .then(data => {
    if (data.ok === 1) {
      console.log('创建成功', data);
      alert(data.msg);
    } else {
      console.log('创建失败', data);
      alert(data.msg);
    }
  })
  .catch(error => {
    console.error('请求异常:', error);
  });
}
```

### 3. 动态构建报价单数据

```javascript
function createPriceDynamic(title, customer, owner, items) {
  const priceData = {
    number: "",
    title: title,
    cu_id: customer,
    who: owner,
    date: new Date().toISOString().split('T')[0],
    type: "服务报价",
    price: items.reduce((sum, item) => sum + item.num * item.price, 0),
    subdata: items
  };

  const param = {
    cmd: "create_data",
    dtname: "price",
    required_skip: 0,
    list: JSON.stringify([priceData])
  };

  return fetch('/system/api.xt', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(param)
  })
  .then(res => res.json());
}
```

### 4. async/await 写法

```javascript
async function createPriceAsync() {
  const param = {
    cmd: "create_data",
    dtname: "price",
    required_skip: 0,
    list: JSON.stringify([
      {
        title: "异步创建报价单",
        cu_id: "梦蝶北京",
        who: "刘琪峰",
        date: "2026-06-03",

        price: 8000,
        subdata: [
          { pro_id: 15537, num: 2, price: 3000, tax_rate: 13 },
          { pro_id: 4, num: 5, price: 400, tax_rate: 13 }
        ]
      }
    ])
  };

  try {
    const res = await fetch('/system/api.xt', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(param)
    });
    const data = await res.json();

    if (data.ok === 1) {
      console.log('创建成功', data);
      return data;
    } else {
      console.log('创建失败', data.msg);
      throw new Error(data.msg);
    }
  } catch (error) {
    console.error('请求异常:', error);
    throw error;
  }
}

// 调用
createPriceAsync().then(data => {
  console.log('处理结果:', data);
}).catch(err => {
  console.error('出错了:', err);
});
```

## 数据处理流程

```
请求 → 参数校验(cmd/dtname/list) → 加载price数据模型 → 遍历list数组
  → loadAPIParam(字段映射与校验) → checkFunTurn(字段函数转换)
  → inputData(保存数据)
    → saveMainDb(保存主表price)
    → saveSubDb(保存子表pricedetail，循环每条明细)
      → addSpecialS(子表特殊处理：自动回填客户ID、币种、汇率，自动计算金额)
  → endDo(后续处理)
← 返回结果
```
