# 使用 load_data 接口获取产品图片

## 接口说明

### 基础地址

```
GET /system/api.xt?cmd=load_data&dtname=product
```

### 参数表

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `cmd` | ✅ | 固定值 `load_data` | `load_data` |
| `dtname` | ✅ | 数据表名，产品表为 `product` | `product` |
| `field` | ❌ | 需要返回的字段，逗号分隔 | `id,pic` |
| `where` | ❌ | 筛选条件，支持 SQL WHERE 语法 | `id=123` / `id=1 OR id=2 OR id=3` |
| `limit` | ❌ | 返回条数上限 | `10` |

### 返回格式

```json
{
  "ok": 1,
  "msg": "读取成功",
  "data": [
    { "pic": "/pic/?1228s&new=1" },
    { "pic": "/images/dproduct.jpg" }
  ],
  "info": {
    "table": "product",
    "tablename": "产品信息",
    "fields": { "pic": "产品图片" }
  }
}
```

- `ok`: `1` 表示成功，非 1 表示失败
- `data`: 记录数组，每条记录包含请求的 `field` 字段
- `pic` 字段值为**图片 URL 路径字符串**

## 使用场景与调用方式

### 场景一：获取单张产品图片

```javascript
// 按 ID 精确查询一张产品的图片
var url = '/system/api.xt?cmd=load_data&dtname=product&field=id,pic&where=' + encodeURIComponent('id=123');
var resp = await fetch(url);
var json = await resp.json();
if (json.ok && json.data && json.data.length > 0) {
  var picUrl = json.data[0].pic; // 如: "/pic/?1228s&new=1"
}
```

### 场景二：批量获取多张产品图片（推荐）

使用 `OR` 条件拼接多个 ID，一次请求获取全部：

```javascript
var ids = [123, 456, 789];
var whereClause = ids.map(function(id) { return 'id=' + id; }).join(' OR ');
// 结果: whereClause = "id=123 OR id=456 OR id=789"

var url = '/system/api.xt?cmd=load_data&dtname=product&field=id,pic&where=' + encodeURIComponent(whereClause);
var resp = await fetch(url);
var json = await resp.json();

// 将结果整理为 ID → URL 的映射
var picMap = {};
if (json.ok && json.data) {
  for (var i = 0; i < json.data.length; i++) {
    var row = json.data[i];
    if (row.id && row.pic) {
      picMap[row.id] = row.pic;
    }
  }
}
// picMap = { "123": "/pic/?1228s&new=1", "456": "/images/dproduct.jpg", ... }
```

### 场景三：分页获取全量图片

当需要获取大量产品图片时，配合 `limit` 分批拉取：

```javascript
var allPics = {};
var offset = 0;
var batchSize = 200;

while (true) {
  var url = '/system/api.xt?cmd=load_data&dtname=product&field=id,pic&limit=' + batchSize;
  var resp = await fetch(url);
  var json = await resp.json();
  if (!json.ok || !json.data || json.data.length === 0) break;

  for (var i = 0; i < json.data.length; i++) {
    var row = json.data[i];
    if (row.id && row.pic) allPics[row.id] = row.pic;
  }

  if (json.data.length < batchSize) break; // 已到末尾
  offset += batchSize;
}
```

## 项目中的实际实现

### 架构设计：内存缓存 + 按需批量加载

项目中采用 **三层策略** 避免重复请求：

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  UI 层渲染   │ ──→ │  内存缓存层   │ ──→ │  API 请求层  │
│ getProductPic │     │ _productPicCache│     │ fetch()     │
│ Url(id)      │     │ {id → url}   │     │ load_data   │
└─────────────┘     └──────────────┘     └─────────────┘
                         ↑ 命中直接返回        ↑ 未命中才请求
                         ↓ 未命中标记防重       ↓ 写入缓存
```

### 核心代码

#### 1. 缓存对象

```javascript
var _productPicCache = {}; // { productId: "picUrl" } 或空字符串(表示已查无图)
```

#### 2. 批量获取函数 `fetchProductPics(ids)`

```javascript
async function fetchProductPics(ids) {
  // 1. 空数组直接返回
  if (!ids || ids.length === 0) return {};

  // 2. 过滤出未缓存的 ID（去重逻辑）
  var needFetch = ids.filter(function(id) {
    return !_productPicCache[id]; // 已缓存（包括空字符串）的跳过
  });
  if (needFetch.length === 0) return _productPicCache;

  // 3. 拼接 OR 条件，发起一次 HTTP 请求
  try {
    var whereClause = needFetch.map(function(id) {
      return 'id=' + id;
    }).join(' OR ');
    var url = '/system/api.xt?cmd=load_data&dtname=product&field=id,pic&where=' +
              encodeURIComponent(whereClause);
    var resp = await fetch(url);
    var json = await resp.json();

    // 4. 响应结果写入缓存
    if (json.ok && json.data) {
      for (var i = 0; i < json.data.length; i++) {
        var row = json.data[i];
        if (row.id && row.pic) _productPicCache[row.id] = row.pic;
      }
    }
  } catch (e) {
    console.warn('fetchProductPics error:', e);
  }

  // 5. 无图片的 ID 也写入空字符串缓存，防止反复请求
  for (var j = 0; j < needFetch.length; j++) {
    if (!_productPicCache[needFetch[j]]) _productPicCache[needFetch[j]] = '';
  }

  return _productPicCache;
}
```

#### 3. 快速读取函数 `getProductPicUrl(id)`

```javascript
function getProductPicUrl(id) {
  return _productPicCache[id] || ''; // O(1) 查找
}
```

### 两处调用点

| 调用位置 | 触发时机 | 获取范围 | 显示规则 |
|----------|----------|----------|----------|
| **`searchProductByInput()`** | 用户在重新匹配弹窗中搜索产品时 | 当前搜索结果的全部候选产品（最多30条） | 所有候选项均显示缩略图（有图显示图片，无图显示占位符） |
| **`renderProductList()`** | 左侧产品列表渲染时 | 仅 `status==='confirmed'` 的已确认产品 | 已确认的显示真实图片，未确认/报错/新建的显示锁定占位符 |

## 图片 URL 说明

接口返回的 `pic` 字段值为相对路径，常见格式：

| 格式示例 | 说明 |
|----------|------|
| `/pic/?1228s&new=1` | 动态图片服务路径（带参数） |
| `/images/dproduct.jpg` | 静态文件路径 |

前端 `<img>` 标签直接引用即可：

```html
<img src="/pic/?1228s&new=1" alt="" loading="lazy">
```

> 注意：`loading="lazy"` 属性启用浏览器原生懒加载，避免一次性加载大量图片造成性能问题。

## 注意事项

1. **where 条件必须 URL 编码** — `encodeURIComponent()` 处理 `OR`、`=` 等特殊字符
2. **空图片也要缓存** — 用空字符串标记"已查无图"，避免同一无图产品反复请求
3. **缓存生命周期** — `_productPicCache` 为页面级内存变量，刷新页面后清空
4. **字段精简** — 只请求 `id,pic` 两个字段，减少传输量
5. **错误容错** — 网络异常时不阻断主流程，仅 console.warn 记录
