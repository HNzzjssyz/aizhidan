第一章 · 快速上手

1.1 系统简介 & 适用场景

超兔-AI 制单 是一个"嵌入到现有 CRM"的浏览器端工具，解决一线业务员每天面对的"录单"工作：

  • 从客户/老板那里拿到手写单据、Excel 截图、AI 生成的 JSON
  • 手工录入到 CRM 系统中（费时、易错）

本工具用 分词+拼音双引擎 解决"模糊匹配"问题（如"爱国者"被写作"aiguo"、"Mini SD"被写作"mirco sd"），用 Coze 智能体 解决"AI 对话辅助"，让录单从分钟级降到秒级。

典型适用场景

📋

客户发来报价单截图

把截图 Ctrl+V 贴入右侧 AI 助手 → 自动解析 → 匹配 CRM 产品 → 一键生成报价单

💬

老板用 AI 写的采购单

老板在豆包/通义/Kimi 上生成 JSON → 复制粘贴到本工具 → 自动匹配 → 一键生成订单

🎙️

电话报价录音转写

语音录入"6 个爱国者迷你王 67 块 88 折 13% 税" → 智能体理解 → 自动填充产品明细

🔄

批量产品询价

20 个产品的 Excel 贴入 → 一键获取价格（含税）→ 导出 Excel 贴回原文档

1.3 5 分钟快速体验

假设你已经登录 CRM 系统，浏览器打开了本工具页面：

  1. 在右侧 AI 助手输入框中输入：给我生成一个示例报价单，3 个爱国者迷你王商务型 L8202，单价 67 块，13% 税
  2. AI 返回一段文字 + JSON 格式的结构化数据
  3. 复制 JSON，回到本工具页面，按 Ctrl+V 粘贴
  4. 左侧"单据草稿"自动出现：客户识别 + 3 行产品明细
  5. 点击"全部确认" → 调整税率（行内下拉，默认 13%）→ 点击"生成销售订单"
  6. 弹窗显示"订单创建成功" → 点击"完成去视图" → 新窗口打开 CRM 订单详情

恭喜你！ 整个流程用时 < 1 分钟，比手工录入快了 10 倍以上。

第三章 · 核心流程 - 智能制单

3.1 录入客户和产品

有 4 种 录入方式：

方式操作适用场景
① AI 对话在右侧 AI 助手中用文字/语音描述需求模糊、想边聊边调整
② 复制 JSON从任意 AI 工具生成 JSON → Ctrl+V 粘贴数据已有结构化形式
③ 单据截图Ctrl+V 粘贴图片到 AI 助手客户发来微信截图/PDF 截图
④ 单据文本纯文本贴入 AI 助手邮件正文、纯文本单据

3.2 复制 AI 生成的 JSON 自动匹配

这是最高效的录入方式。流程：

  1. 在任意 AI 工具（豆包/通义/Kimi/ChatGPT）生成结构化 JSON
  2. 在 AI 回复中找到 JSON 块（用 ```json 包裹的代码块）
  3. 点击代码块右上角的"复制"按钮
  4. 切换回本工具页面，按 Ctrl+V 粘贴
  5. 系统自动识别 JSON 格式 → 触发匹配流程
📥
JSON 粘贴触发匹配
页面顶部弹出绿色 Toast："已捕获订单JSON，匹配耗时 235ms"

3.2.1 支持的 JSON 字段

字段必填说明
cu_id 或 customer是客户名称
subject / title否订单主题（用于报价单/订单）
pro_name / name / pn是产品名 / 品名 / 编号
qty / amount / num是数量
price / un_price是单价
discount / zk否折扣（百分比）
tax_rate否税率（0/3/5/6/9/13）

3.2.2 标准化 JSON 示例

[
  {
    "cu_id": "上海飞奥德",
    "subject": "2026-Q2 报价",
    "subdata": [
      { "pro_name": "爱国者迷你王 商务型 L8202(16G)", "qty": 6, "price": 67, "discount": 88, "tax_rate": 5 },
      { "pro_name": "金士顿 Micro SD卡(16G)", "qty": 4, "price": 56, "discount": 99, "tax_rate": 6 }
    ]
  }
]

本工具会自动尝试标准化各种 AI 输出格式（即使字段名不一样），但标准字段名识别成功率最高。

3.3 单据截图贴入

  1. 在微信/邮件/PDF 中看到单据图片
  2. 用截图工具（微信自带 / 系统截图 / Snipaste）截取单据区域
  3. 复制图片（Ctrl+C 或右键复制）
  4. 回到本工具页面，按 Ctrl+V 粘贴
  5. 图片自动转发到右侧 AI 助手上传框
  6. 在 AI 助手中加一句"请解析这张图并返回 JSON"
  7. AI 返回 JSON 后再按 3.2 的流程走一次

增强体验：本工具做了图片粘贴全局监听，即使焦点不在 AI 助手的输入框，按 Ctrl+V 也会自动把图片喂给 Coze SDK。

3.4 单据文本贴入

如果客户发的是纯文本（如邮件正文），直接复制文本贴入 AI 助手，让 AI 提取信息即可。本工具暂不直接解析纯文本（避免误识别），统一走 AI 助手中转。

第五章 · 产品匹配

5.1 匹配模式（精确 / 品名 / 拼音 / 混合）

本工具使用4 套匹配策略，按优先级依次尝试：

优先级策略适用场景示例
1 编号精确匹配 AI 给出了产品编号 编号 = "P001" → 直接命中
2 品名精确匹配 品名完全一致 "爱国者迷你王" = "爱国者迷你王"
3 拼音匹配 客户写错字、音近字 "爱国者" → aiguo → aiguo
4 分词匹配 产品名拆解后部分命中 "爱国者迷你王 商务型 L8202" → 拆成 ["爱国者","迷你王","商务型","L8202"]

双擎：分词 + 拼音并行运行，谁先命中就用谁，匹配速度快（< 300ms 处理 50 个产品）。

5.2 匹配结果状态

每个产品行有 5 种状态标签：

标签颜色含义
编号匹配绿按产品编号精确命中
品名匹配绿按品名精确命中
拼音匹配黄按拼音首字母命中
分词匹配黄按分词命中
候选 X橙未匹配到，弹候选让用户选

5.3 行内编辑（数量/单价/折扣）

数量、单价、折扣三列点击即可编辑：

  1. 点击单元格，背景变黄
  2. 直接输入新值
  3. 按 Enter 或点击其他位置保存

  4. 点"保存并确认" → 新产品入库 + 自动匹配当前单据

第六章 · 价格与税率

6.1 折扣

折扣是百分比（0~100），可编辑：

  • 100% = 不打折
  • 88% = 88 折
  • 50% = 5 折

小数折扣：本工具支持 95.5% 这样的小数折扣（修复了早先 parseInt 截断 bug）。

6.2 税率（行内 + 统一）

本系统支持 6 个税率档位：0% / 3% / 5% / 6% / 9% / 13%。

6.2.1 行内税率下拉（每行独立）

每行产品都有一个税率下拉框：

💲
行内税率下拉
下拉选项：0% / 3% / 5% / 6% / 9% / 13% / 锁图标（手动改过）
  • 默认 13%（最常见）
  • 手动改过某行后，右边出现 锁图标
  • 锁定的行不会被"统一税率"批量覆盖

6.2.2 统一税率工具栏（批量设置）

在"操作按钮区"上方有一行工具栏：

🔧
统一税率工具栏
下拉选择税率 + "应用到未锁定的行" 按钮 + 锁图标说明

操作步骤：

  1. 从下拉选择目标税率（如 13%）
  2. 点"应用到未锁定的行"按钮
  3. 所有未手动改过的行税率都变成 13%
  4. 已锁定的行（带锁图标）保持原值

6.3 含税金额自动计算

本工具的含税计算公式（符合中国增值税计税基础）：

含税单价 = un_price × (1 + taxRate/100)
税金     = qty × un_price × taxRate/100   ← 基于原价，**不受折扣影响**
订单 sum = qty × un_price × zk/100 + tax_money
报价单 money = (1 + tax_rate/100) × num × price   ← 折扣已折入 price

实时刷新：改数量/单价/折扣/税率任意一项，"含税小计"自动重算，"总金额"自动汇总。

6.4 一键获取价格（自动核价）

在所有产品确认匹配完成后，可使用"一键获取价格"功能：

⚡
一键获取价格按钮
橙黄色按钮，在"创建报价单"左侧
  1. 点"一键获取价格" → 弹出"价格获取"弹窗
  2. 弹窗显示每个产品的可选价格档（标准价 / 客户历史价 / 促销价）
  3. 逐项勾选确认（或点"全部按最低价"）
  4. 点"确认获取" → 批量更新单价 + 自动刷新含税小计

第七章 · 单据生成

7.1 创建报价单

  1. 确保所有产品都已确认（"已确认 X/X" 等于总数）
  2. 点击"创建报价单"按钮
  3. 系统自动按公式计算 money = num × price × (1 + tax_rate/100)
  4. 弹窗显示"报价单创建成功"+ 报价单ID
  5. 点"完成去视图" → 新窗口打开 CRM 报价单详情

7.2 创建销售订单

  1. 确保所有产品都已确认
  2. 点击"生成销售订单"按钮（蓝色主按钮）
  3. 系统按公式计算 sum = amount × un_price × zk/100 + tax_money
  4. 弹窗显示"订单创建成功" + 订单ID + 订单总额
  5. 点"完成去视图" → 新窗口打开 CRM 订单详情
🎉
订单创建成功弹窗
订单主题 / 订单ID / 明细数量 / 订单总额 + [关闭] [完成去视图] 按钮

7.3 完成去视图（自动跳 CRM 详情）

订单/报价单创建成功后，"完成去视图"按钮会自动：

  • 从 API 响应中取 id（新生成的主表 ID）
  • 新窗口打开对应的 CRM 详情页：
  • 订单 → /xcrm/contract/contract/detail.xt?id=<id>
  • 报价单 → /xcrm/tracing/price/detail.xt?id=<id>

无需手动复制 ID 拼 URL，一键直达 CRM 详情页，方便立即做后续操作（如打印、加备注、关联项目）。

7.4 导出 Excel（贴右边）

如果客户发来的是 Excel 格式的询价单，导出时可保持原文档格式：

  1. 点"导出 Excel（贴右边）"按钮
  2. 下载一个 .xlsx 文件，含产品图
  3. 打开客户原询价单，把下载的文件贴到右侧（即原文档的"产品明细"列）
  4. 原文档的标题/客户信息保持不变，产品列被自动填充

第十章 · 常见问题 FAQ

Q1: 粘贴 JSON 后没反应？

A: 检查 JSON 格式：必须用 ```json 代码块包裹，或确保是合法 JSON 数组/对象。本工具会忽略非 JSON 内容。

Q2: 客户匹配不到？

A: 三种可能：① CRM 中无此客户 → 需先去 CRM 创建；② 简称写错 → 手动搜索；③ 名称太泛（如"公司"）→ 提供更具体名称。

Q3: 产品匹配错（匹配到不相关产品）？

A: 点"重新匹配" → 选其他候选 → 必要时点"创建新产品"。本工具有冲突订单保护（同一 CRM 订单内产品不可重复）。

Q4: 税率下拉怎么默认是 13%？可以改成 0% 吗？

A: 可以。改法：① 行内下拉直接选；② 工具栏"统一税率"批量改。本系统对税率有校验（必须是 0/3/5/6/9/13 之一），其他值会被自动修正为 0。

Q5: 创建订单时报"折扣格式错误"？

A: 折扣必须是百分比数字（如 88），不要写"88%"或"0.88"。本工具会自动补上 "%"。

Q6: CRM 后端显示的税率和我选的不一样？

A: 这是已知的 CRM 显示层 bug：CRM 的"税率"列读产品主表的默认税率（不是子表传入的）。实际入库的税率/税金是正确的。已加 Console 调试日志，下单时可在控制台看到实际发送值。

Q7: 智能体没反应 / 加载失败？

A: ① 检查网络（Coze CDN 国外可能慢）；② 刷新页面重试；③ 点"⚙️ 配置"切换到"默认"智能体；④ 浏览器控制台查看错误信息。

Q8: 一键获取价格没数据？

A: ① 该客户没有历史订单 → 需先手动维护价格；② CRM 价格表无数据 → 联系 CRM 管理员。

Q9: 导出 Excel 后产品图没显示？

A: ① 产品图需要预先同步（拼音工具页面）；② 浏览器安全策略禁止外链图片时也会失败；③ 试用 Excel 2016+ 打开 .xlsx。

Q10: 报"请先完成所有产品匹配"？

A: 有产品还在"候选"状态（橙色标签），需手动选择匹配项或创建新产品。
