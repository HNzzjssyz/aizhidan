🔍一、现状分析

1.1 后端接口对税率的支持

根据 读取数据接口/创建订单接口.md 和 读取数据接口/创建报价单接口.md 的字段定义：

① 订单子表（goods）已支持 4 个税率相关字段

字段 中文名 类型 必填 说明
tax_rate 税率 number 否 税率百分比，如 13 表示 13%
tax_money 税金 number 否 税金金额（需前端预计算后传入）
un_price_tax 含税单价 number 否 含税单价（前端计算后传入）
sum 金额 number 否 为 0 时系统自动计算：amount × un_price × zk/100 + tax_money
⚠️
关键发现：订单接口的 tax_money 是「需要前端传入」的，不会自动计算。 这与报价单不同——报价单子表的 money 字段在 tax_rate 存在时会自动套用 (1 + tax_rate/100) × num × price。

② 报价单子表（pricedetail）已支持 1 个税率字段

字段 中文名 类型 必填 说明
tax_rate 税率 number 否 税率百分比，如 20 表示 20%
money 金额 number 否 为 0 时系统自动计算：(1 + tax_rate/100) × num × price
💡
报价单的便利：只要传 tax_rate 和 num/price，money 系统会自动算含税。前端只传 tax_rate 即可，零计算负担。

2.3 计算公式

① 单条产品行

字段 公式 说明
含税单价 price × (1 + taxRate / 100) 前端实时计算
税金 qty × price × taxRate / 100 前端子表传入 tax_money
含税金额 qty × 含税单价 × discount / 100 前端展示用，发单时给后端

② 订单总金额（混搭税率）

// 订单主表 sum = Σ(子表 sum)；子表 sum 由后端按公式计算
// 后端公式：sum = amount × un_price × zk/100 + tax_money
// 前端只算 tax_money 传入即可

function buildOrderSubdata(products) {
  return products.map(p => {
    const taxRate = p.taxRate || 0;
    const unPrice = parseFloat(p.price) || 0;
    const qty = parseFloat(p.qty) || 0;
    const zk = (p.discount || 100) / 100;

    const unPriceTax = +(unPrice * (1 + taxRate / 100)).toFixed(2);
    const taxMoney = +(qty * unPrice * taxRate / 100).toFixed(2);
    const sum = +(qty * unPrice * zk + taxMoney).toFixed(2);  // 冗余，后端会重算

    return {
      name: p.matchedId,
      pn: p.matchedName,
      pm: p.matchedSku,
      amount: qty,
      un_price: unPrice,
      zk: (p.discount || 100) + '%',
      tax_rate: taxRate,
      tax_money: taxMoney,
      un_price_tax: unPriceTax,
      sum: sum
    };
  });
}

function buildOrderMain(subdata) {
  const totalSum = subdata.reduce((s, x) => s + x.sum, 0);
  const totalTax = subdata.reduce((s, x) => s + x.tax_money, 0);
  const totalNoTax = +(totalSum - totalTax).toFixed(2);

  return {
    number: '',
    subject: '...自动从 AI 提取...',
    cu_id: currentCustomer.matchedName,
    date: new Date().toISOString().slice(0, 10),
    status: '执行中',
    sum: totalSum,            // 含税总金额
    subdata: subdata
  };
}

function buildPriceSubdata(products) {
