剪贴板监听最终方案

智能制单 · dexiedb · Coze 智能体在右侧时的剪贴板捕获
模块：dexiedb/index.html  |  行号：约 1913-1976（prod / dev 一致）

一、背景与目标

在智能制单界面，Coze 智能体对话窗口位于页面右侧（iframe 嵌入）。最终用户工作流是：

  1. 在右侧 Coze 对话框里描述采购需求（如"我要给 〖飞奥德〗 下单：金士顿 CF 8G 5 个"）；
  2. Coze 智能体生成结构化 JSON；
  3. 用户点击 Coze 输出上的"复制"按钮，把 JSON 复制到系统剪贴板；
  4. 左侧智能制单面板自动捕获该 JSON，识别为有效订单后启动客户/产品匹配、价格计算、下单流程。

整个过程不允许"用户切回左侧再按 Ctrl+V"这种打断，必须做到复制即触发。

二、关键挑战

挑战说明
复制源是 Coze iframe Coze 是第三方 iframe，copy 事件不冒泡到父页；paste 事件也只在父页有焦点时触发。
Clipboard API 的读取时机 navigator.clipboard.readText() 只在页面获得焦点且用户授权后可用，且必须用户手势后立即调用，否则 PENDING。
静默式自动捕获 不能在每次轮询都弹 toast / 干扰用户；3 秒轮询本身就意味着同一个内容会被读到多次。
JSON 误识别 用户可能复制其它任何内容（链接、密码、文件路径……），必须先做"是不是订单 JSON"的预判。

三、最终方案概览

页面加载 → setInterval(tryReadClipboard, 3000) → 窗口获焦 / 切回前台 → 延时 200/800/1500 ms 再读 3 次 → 用户主动 paste 到结果区 → tryReadClipboard(text) → 4 道闸门 → handleClipboardText(text)

核心 三条触发路径（轮询 / 焦点 / paste）最终汇入同一个 tryReadClipboard 函数，由它统一做 4 道闸门过滤。

四、4 道闸门：tryReadClipboard 的内部过滤

function tryReadClipboard() {
  // 闸门 1：页面无焦点 → 不读
  if (!document.hasFocus()) {
    console.log('[clipboard] 拦截：页面无焦点');
    return;
  }
  // 闸门 2：Clipboard API 不可用 → 跳过
  if (!navigator.clipboard || !navigator.clipboard.readText) {
    console.log('[clipboard] 拦截：剪贴板 API 不可用');
    return;
  }
  navigator.clipboard.readText().then(function(text) {
    // 闸门 3：剪贴板没变 → 静默跳过（轮询常态）
    if (text === lastClipboardContent) {
      console.log('[clipboard] 拦截：剪贴板未变');
      return;
    }
    // 闸门 4：是已经处理过的同一段 JSON → 静默跳过
    if (text === lastDetectedJSON) {
      console.log('[clipboard] 拦截：是已处理过的 JSON');
      return;
    }
    // 闸门 5：不是订单 JSON → 静默跳过
    if (!isOrderJSON(text)) {
      console.log('[clipboard] 拦截：不是订单 JSON');
      return;
    }
    console.log('[clipboard] 通过：开始处理');
    lastClipboardContent = text;
    handleClipboardText(text);
  }).catch(function(e) {
    console.log('[clipboard] 异常：', e);
  });
}
闸门作用失败行为
1. document.hasFocus()避免在用户操作 Coze iframe 时误触发静默 return，不弹任何提示
2. Clipboard API 存在性兼容老浏览器 / Safari 非 https静默 return
3. 剪贴板未变 lastClipboardContent3 秒轮询的常态拦截静默 return（不提示）
4. 已处理过的 JSON lastDetectedJSON防止同一次复制在多路径下被重复处理静默 return
5. isOrderJSON() 预判只接受订单 JSON，过滤杂七杂八的复制静默 return

设计要点 5 道闸门一律静默（仅 console.log 给开发者看），不向用户弹任何提示。理由详见第六节。

五、订单 JSON 预判：isOrderJSON

为避免把任意复制内容（如网址、命令、密码）当成订单处理，需要先做"是不是订单 JSON"的预判。实现非常轻量——只检查常见订单字段的特征子串：

function isOrderJSON(text) {
  if (!text || text.length < 10) return false;
  if (text.indexOf('{') === -1) return false;
  // 命中任一"订单特征字段"即视为候选订单 JSON
  return text.indexOf('"customer_name"') !== -1 ||
         text.indexOf('"customerName"') !== -1 ||
         text.indexOf('"customer"') !== -1 ||
         text.indexOf('"客户"') !== -1 ||
         text.indexOf('"doc_type"') !== -1 ||
         text.indexOf('"products"') !== -1 ||
         text.indexOf('"items"') !== -1 ||
         text.indexOf('"产品"') !== -1;
}

这是粗筛，不是为了"严格解析"。真正的提取由 PinyinMatch.extractOrderJSON 完成（详见结论文档 监听chat sdk的可行方案.html）。

六、为何重复时静默过滤，而不弹"重复复制"提示

问题 一开始的需求是"重复复制时给个黄色 toast 提醒"，但调试中发现：

6.1 现象：3 秒轮询下任何标记都会被反复消耗

监听采用 setInterval(tryReadClipboard, 3000)。每次轮询都会重新调用 navigator.clipboard.readText()，只要剪贴板内容没变就反复进入"未变"分支。

  • 第一次轮询：text 变 → 通过 → 标记 lastDupNoticed = true
  • 第二次轮询（3 秒后）：text 仍然 = lastClipboardContent → 走"未变"分支 → 已无法在那一帧做"重复判断"
  • 如果用 lastDupNoticed 计数 / 节流：额度会立刻被用完

6.2 多种节流方案全部回退

方案问题结论
布尔标记 lastDupNoticed + 60s 解锁 用户说"60 秒兜底没看懂"，且这种节流对"短时间内多次复制不同 JSON"的场景不友好 回退
toast "重复复制"提示 + 计数 用户测试后反馈"功能不稳，提示逻辑颠倒" 回退
toast "已处理" 提示 3 秒轮询每轮都触发，提示被轰炸 回退
改用 paste 事件触发 Coze iframe 内的复制不会触发父页 paste 不可行

6.3 结论：识别到重复即静默过滤

最终采用最朴素的"两次去重"：

  • lastClipboardContent：闸门 3，挡住"剪贴板本身没动"的常态轮询。
  • lastDetectedJSON：闸门 4，挡住"已经处理过的同一段 JSON"。

两道闸门都在 tryReadClipboard 入口静默 return，不抛错、不弹 toast、不写入业务状态。用户感受就是"复制了 → 立刻处理；再复制同样的 → 没反应（符合预期）"。

经验 当一个监听是 3 秒级轮询、且触发条件天然会去重时，不要试图再加一层用户提示。提示会让 3 秒节拍变成噪音。静默过滤是这种场景下唯一可接受的体验。

七、最终代码（dexiedb/prod/index.html 1913-1976 行，dev 同源）

// ===== 剪贴板监听逻辑 =====

// 状态：上一次读到的剪贴板原始文本（闸门 3 用）
var lastClipboardContent = '';
// 状态：轮询 timer 句柄
var clipboardPollTimer = null;

// 1) 订单 JSON 粗筛：命中任一"订单特征字段"即视为候选
function isOrderJSON(text) {
  if (!text || text.length < 10) return false;
  if (text.indexOf('{') === -1) return false;
  return text.indexOf('"customer_name"') !== -1 ||
         text.indexOf('"customerName"') !== -1 ||
         text.indexOf('"customer"') !== -1 ||
         text.indexOf('"客户"') !== -1 ||
         text.indexOf('"doc_type"') !== -1 ||
         text.indexOf('"products"') !== -1 ||
         text.indexOf('"items"') !== -1 ||
         text.indexOf('"产品"') !== -1;
}

// 2) 核心：5 道闸门。命中即静默 return；只有完整通过才调用 handleClipboardText
function tryReadClipboard() {
  if (!document.hasFocus()) { console.log('[clipboard] 拦截：页面无焦点'); return; }
  if (!navigator.clipboard || !navigator.clipboard.readText) {
    console.log('[clipboard] 拦截：剪贴板 API 不可用');
    return;
  }
  navigator.clipboard.readText().then(function(text) {
    if (text === lastClipboardContent) { console.log('[clipboard] 拦截：剪贴板未变'); return; }
    if (text === lastDetectedJSON)     { console.log('[clipboard] 拦截：是已处理过的 JSON'); return; }
    if (!isOrderJSON(text))            { console.log('[clipboard] 拦截：不是订单 JSON'); return; }
    console.log('[clipboard] 通过：开始处理');
    lastClipboardContent = text;
    handleClipboardText(text);
  }).catch(function(e) { console.log('[clipboard] 异常：', e); });
}

// 3) 路径 A：用户在结果区手动 paste（兜底）
var resultArea = document.getElementById('resultSection');
if (resultArea) {
  resultArea.addEventListener('paste', function(e) {
    var text = (e.clipboardData || window.clipboardData).getData('text');
    if (text && isOrderJSON(text)) {
      lastClipboardContent = text;
      handleClipboardText(text);
    }
  });
}

// 4) 路径 B：窗口获焦时延时读 3 次（200 / 800 / 1500ms），覆盖 Coze 复制→焦点切回这段真空期
window.addEventListener('focus', function() {
  setTimeout(tryReadClipboard, 200);
  setTimeout(tryReadClipboard, 800);
  setTimeout(tryReadClipboard, 1500);
});

// 5) 路径 C：可见性变化时启动/停止轮询
document.addEventListener('visibilitychange', function() {
  if (!document.hidden) {
    setTimeout(tryReadClipboard, 300);              // 立即补一刀
    if (!clipboardPollTimer) {
      clipboardPollTimer = setInterval(tryReadClipboard, 3000);  // 启动 3 秒轮询
    }
  } else {
    if (clipboardPollTimer) {
      clearInterval(clipboardPollTimer);
      clipboardPollTimer = null;                     // 离开页面就停，省电
    }
  }
});

// 6) 启动轮询
clipboardPollTimer = setInterval(tryReadClipboard, 3000);

// 7) 初始化 lastClipboardContent = 当前剪贴板（首次加载时剪贴板里可能已经有 JSON，避免首轮就触发）
if (navigator.clipboard && navigator.clipboard.readText) {
  navigator.clipboard.readText().then(function(text) {
    if (text) lastClipboardContent = text;
  }).catch(function() {});
}

八、可复用骨架（抽离 5 个钩子，方便后续项目直接套用）

把剪贴板监听抽成 5 个职责清晰的钩子，复制到任何新项目时只需替换其中 3 个：

钩子职责本项目实现复用时替换？
isCandidate(text) 判断剪贴板内容是否值得处理 isOrderJSON（订单特征字段） ✅ 必须替换
handle(text) 真正执行业务的入口 handleClipboardText（解析→匹配→渲染） ✅ 必须替换
extractInnerJSON(text) 从原始文本里抠出标准 JSON（去 markdown 包裹 / 找首个 {...}） PinyinMatch.extractOrderJSON ✅ 必须替换
onReset() 何时清空"已处理"标记，让用户能再次触发同段 JSON 用户点"清空/重新开始"时 lastDetectedJSON = '' ⚪ 可选
isActive() 本次是否要尝试读取（替代硬编码的 document.hasFocus()） document.hasFocus() ⚪ 可选

8.1 通用骨架（可直接拷贝）

/**
 * 通用剪贴板监听骨架
 * 用法：替换 3 个 ✅ 钩子即可适配任意业务
 */
var ClipboardWatcher = (function() {
  // === 状态 ===
  var lastRaw = '';      // 闸门：上次读到的原始文本
  var lastHandled = '';  // 闸门：上次完整处理过的文本
  var pollTimer = null;
  var POLL_MS = 3000;

  // === 钩子 1：是否值得处理（粗筛）===
  function isCandidate(text) {
    // ✅ 必须替换：例如判断"是否含某业务特征字段"
    return text && text.length >= 10 && text.indexOf('{') !== -1;
  }

  // === 钩子 2：抽 JSON 子串 ===
  function extractInnerJSON(text) {
    // ✅ 必须替换：用业务自己的 JSON 提取策略
    return text;
  }

  // === 钩子 3：真正执行业务 ===
  function handle(text) {
    // ✅ 必须替换：业务入口
    console.log('已处理剪贴板内容，长度=', text.length);
  }

  // === 钩子 4（可选）：何时重置"已处理"标记 ===
  function onReset() { lastHandled = ''; lastRaw = ''; }

  // === 钩子 5（可选）：本次是否要尝试读取 ===
  function isActive() { return document.hasFocus(); }

  // === 核心：5 道闸门 ===
  function tryRead() {
    if (!isActive())        { console.log('[cw] skip: not active'); return; }
    if (!navigator.clipboard || !navigator.clipboard.readText) {
      console.log('[cw] skip: API unavailable'); return;
    }
    navigator.clipboard.readText().then(function(text) {
      if (text === lastRaw)     { console.log('[cw] skip: raw unchanged'); return; }
      if (text === lastHandled) { console.log('[cw] skip: already handled'); return; }
      if (!isCandidate(text))   { console.log('[cw] skip: not candidate'); return; }
      console.log('[cw] accept, length=', text.length);
      lastRaw = text;
      handle(extractInnerJSON(text) || text);
    }).catch(function(e) { console.log('[cw] error:', e); });
  }

  // === 启动 / 停止 ===
  function start() {
    if (pollTimer) return;
    // 路径 1：3 秒轮询
    pollTimer = setInterval(tryRead, POLL_MS);
    // 路径 2：窗口获焦时连续读 3 次
    window.addEventListener('focus', function() {
      setTimeout(tryRead, 200);
      setTimeout(tryRead, 800);
      setTimeout(tryRead, 1500);
    });
    // 路径 3：可见性变化
    document.addEventListener('visibilitychange', function() {
      if (!document.hidden) {
        setTimeout(tryRead, 300);
        if (!pollTimer) pollTimer = setInterval(tryRead, POLL_MS);
      } else {
        if (pollTimer) { clearInterval(pollTimer); pollTimer = null; }
      }
    });
    // 路径 4：用户主动 paste
    var resultArea = document.getElementById('resultSection');
    if (resultArea) {
      resultArea.addEventListener('paste', function(e) {
        var text = (e.clipboardData || window.clipboardData).getData('text');
        if (text && isCandidate(text)) {
          lastRaw = text;
          handle(extractInnerJSON(text) || text);
        }
      });
    }
    // 初始化：把当前剪贴板内容存进 lastRaw，避免首轮误触发
    if (navigator.clipboard && navigator.clipboard.readText) {
      navigator.clipboard.readText().then(function(text) {
        if (text) lastRaw = text;
      }).catch(function() {});
    }
  }

  function stop() {
    if (pollTimer) { clearInterval(pollTimer); pollTimer = null; }
  }

  return { start: start, stop: stop, reset: onReset, tryRead: tryRead };
})();

// === 启动 ===
ClipboardWatcher.start();

九、调试日志约定

5 道闸门一律打 console.log('[clipboard] 拦截：xxx')，方便在 F12 Console 里追"为什么这次没触发"：

日志含义
[clipboard] 拦截：页面无焦点用户操作在 Coze iframe，父页失焦
[clipboard] 拦截：剪贴板 API 不可用浏览器不兼容或非 https
[clipboard] 拦截：剪贴板未变3 秒轮询常态，不是 bug
[clipboard] 拦截：是已处理过的 JSON用户再次复制同一段 JSON，已静默过滤
[clipboard] 拦截：不是订单 JSON用户复制了别的内容（如网址），符合预期
[clipboard] 通过：开始处理真正进入业务
[clipboard] 异常：...Clipboard API 抛错（权限被拒、文档失焦等）

十、易踩的坑

坑原因规避
Coze iframe 内复制不触发父页 copy/paste 事件 事件不会跨 iframe 冒泡 用轮询 + 主动 readText，不依赖事件
用户点 Coze 复制按钮时父页失焦，toast 不弹 toast 实现监听 document.hasFocus() 监听器入口先 hasFocus() 判断，非焦点直接 return
首次启动时剪贴板里已有 JSON，首轮误触发 没有 lastClipboardContent 初始值 页面加载时立即 readText 一次，把当前内容写入 lastRaw
3 秒轮询被 console 警告轰炸 开发时开 DevTools，Clipboard API 在非焦点时抛 NotAllowedError .catch 静默；只 console.log 一次即可
用户清空结果后再次复制同一段 JSON 不触发 lastDetectedJSON 仍命中 "清空/重新开始" 按钮里调 lastDetectedJSON = ''
