获取产品图片嵌入Excel

开发文档 · 记录从图片获取到Excel嵌入的完整技术方案与踩坑历程

1. 需求背景

在AI制单页面中，用户确认产品匹配后，需要将产品明细（含图片）导出为Excel文件。核心挑战：

  • 产品图片存储在阿里云OSS，通过服务器302重定向访问
  • 图片URL需要鉴权（服务器Cookie + OSS签名）
  • Excel中图片必须嵌入文件，不能使用URL引用（离线不可用）

2. 图片URL的真实链路

页面上的图片URL看似简单，实际经历了服务器重定向：

/pic/?84s&new=1
→
服务器302重定向
→
https://xt-upload.oss-cn-hangzhou.aliyuncs.com/d002/product/1/aa5b...?OSSAccessKeyId=...&Signature=...
关键发现 /pic/?84s&new=1 不是图片文件本身，而是服务器端的302重定向入口。服务器验证用户Cookie后，返回302跳转到阿里云OSS的签名URL（自带AccessKeyId + Signature）。

3. 技术方案演进

方案一：Image + crossOrigin + Canvas
用 new Image() 加载图片，设置 crossOrigin='anonymous'，Canvas绘制后 toDataURL() 转Base64
❌ crossOrigin='anonymous' 导致带Cookie的同源请求被拒绝，图片加载失败；Canvas被污染后toBlob回调不触发，Promise永远挂起
方案二：SheetJS (xlsx) + Base64文本
SheetJS社区版写入Base64字符串到单元格
❌ SheetJS社区版不支持图片嵌入，Base64只能作为文本显示，Excel中看到的是乱码字符串
方案三：fetch + credentials:'include' + Blob
用 fetch(url, {credentials:'include'}) 获取图片Blob，转ArrayBuffer传给ExcelJS
❌ CORS冲突：fetch跟随302到OSS后，credentials模式与OSS的 Access-Control-Allow-Origin: * 不兼容
方案四：Image + Canvas（不设crossOrigin）
去掉crossOrigin属性，同源图片自动带Cookie，Canvas绘制后toBlob
❌ 服务器返回的图片经302重定向后Canvas被标记为"污染"(tainted)，toBlob回调不触发
方案五（最终）：fetch() 默认模式 + ArrayBuffer
用 fetch(url) 不带credentials，跟随302到OSS签名URL，直接获取ArrayBuffer
✅ 成功！同源请求自动带Cookie完成鉴权，重定向到OSS后签名URL自带鉴权不需要Cookie，默认模式与CORS *兼容

4. 最终方案详解

4.1 为什么 fetch() 不带 credentials 能成功？

请求阶段URLcredentials行为鉴权方式
第1次请求/pic/?84s&new=1（同源）默认 same-origin，自动带Cookie服务器验证Cookie → 302
第2次请求（重定向）OSS签名URL（跨域）默认 same-origin，不带CookieOSS签名URL自带AccessKeyId+Signature
核心原理 fetch(url) 默认 credentials: 'same-origin'：同源请求带Cookie（完成服务器鉴权），跨域请求不带Cookie（与OSS的 Access-Control-Allow-Origin: * 兼容）。而 credentials: 'include' 要求跨域响应的 Allow-Origin 不能是通配符 *，恰好与OSS配置冲突。

4.2 完整代码

4.2.1 图片URL获取（load_data接口）

async function fetchProductPics(ids) {
  if (!ids || ids.length === 0) return {};
  var needFetch = ids.filter(function(id) {
    return !_productPicCache[String(id)];
  });
  if (needFetch.length === 0) return _productPicCache;
  try {
    var whereClause = needFetch.map(function(id) {
      return 'id=' + id;
    }).join(' OR ');
    var url = API_BASE + '/api.xt?cmd=load_data&dtname=product&field=id,pic&where='
              + encodeURIComponent(whereClause);
    var resp = await fetch(url);
    var json = await resp.json();
    if (json.ok && json.data) {
      for (var i = 0; i < json.data.length; i++) {
        var row = json.data[i];
        if (row.id && row.pic) {
          _productPicCache[String(row.id)] = row.pic;
        }
      }
    }
  } catch (e) {
    console.warn('fetchProductPics error:', e);
  }
  for (var j = 0; j < needFetch.length; j++) {
    var cacheKey = String(needFetch[j]);
    if (!_productPicCache[cacheKey]) _productPicCache[cacheKey] = '';
  }
  return _productPicCache;
}

4.2.2 URL读取（含HTML实体解码）

function getProductPicUrl(id) {
  var key = String(id);
  var val = _productPicCache[key];
  if (val === undefined || val === null || val === '') return '';
  // 服务器返回的pic字段可能包含HTML实体编码
  return val.replace(/&/g, '&')
            .replace(/</g, '<')
            .replace(/>/g, '>')
            .replace(/"/g, '"')
            .replace(/'/g, "'");
}

4.2.3 图片尺寸获取（比例控制）

产品图片原始尺寸各异（横图、竖图、正方形），如果强制写入固定宽高会导致变形。需要先获取原始尺寸，再按比例缩放到单元格区域内。

function _getImageDimensions(buf) {
  return new Promise(function(resolve) {
    var blob = new Blob([buf]);
    var url = URL.createObjectURL(blob);
    var img = new Image();
    img.onload = function() {
      URL.revokeObjectURL(url);
      resolve({ width: img.naturalWidth, height: img.naturalHeight });
    };
    img.onerror = function() {
      URL.revokeObjectURL(url);
      resolve({ width: 140, height: 140 }); // 降级为正方形
    };
    img.src = url;
  });
}
原理 将 ArrayBuffer 转为 Blob URL，用 Image.naturalWidth / naturalHeight 获取图片原始像素尺寸。此方式不依赖 Canvas，不受跨域污染限制。

4.2.4 图片二进制获取（核心函数）

function picUrlToArrayBuffer(url) {
  if (!url || url === '') {
    return _placeholderArrayBuffer().then(function(buf) {
      return { buffer: buf, width: 140, height: 140 };
    });
  }
  // 关键：不设 credentials，使用默认 same-origin 模式
  return fetch(url)
    .then(function(resp) {
      if (!resp.ok) throw new Error('HTTP ' + resp.status);
      return resp.arrayBuffer();
    })
    .then(function(buf) {
      if (!buf || buf.byteLength === 0) {
        return _placeholderArrayBuffer().then(function(b) {
          return { buffer: b, width: 140, height: 140 };
        });
      }
      // 获取原始尺寸，与buffer一起返回
      return _getImageDimensions(buf).then(function(dim) {
        return { buffer: buf, width: dim.width, height: dim.height };
      });
    })
    .catch(function(e) {
      console.warn('picUrlToArrayBuffer: fetch failed for', url, e.message);
      return _placeholderArrayBuffer().then(function(buf) {
        return { buffer: buf, width: 140, height: 140 };
      });
    });
}
返回值结构 函数返回 { buffer: ArrayBuffer, width: number, height: number }，同时携带图片二进制数据和原始尺寸，供后续按比例缩放使用。

4.2.5 Excel导出（ExcelJS + 图片等比缩放嵌入）

async function exportProductExcel() {
  // 1. 获取产品图片URL缓存
  var productMap = await getLSProductMap();
  var allIds = currentProducts.map(function(p) {
    return p.matchedId || p.id;
  }).filter(Boolean);
  if (allIds.length > 0) await fetchProductPics(allIds);

  // 2. 组装行数据
  var rows = [];
  for (var i = 0; i < currentProducts.length; i++) {
    var p = currentProducts[i];
    var lookupId = p.matchedId || p.id;
    var info = productMap[String(lookupId)] || {};
    rows.push({
      name: info.name || p.matchedName || p.originalName || '',
      sku: info.sku || p.matchedSku || p.newSku || '-',
      code: info.code ? ('PRD-' + info.id) : (p.matchedCode || p.newCode || '-'),
      price: p.price || '-',
      qty: p.qty || '-',
      note: p.note || '-',
      picUrl: getProductPicUrl(lookupId)
    });
  }

  // 3. 批量获取图片ArrayBuffer
  var picBuffers = await Promise.all(
    rows.map(function(r) { return picUrlToArrayBuffer(r.picUrl); })
  );

  // 4. 创建ExcelJS工作簿
  var wb = new ExcelJS.Workbook();
  var ws = wb.addWorksheet('产品明细');
  ws.columns = [
    { header: '图片', key: 'pic', width: 20 },
    { header: '产品名称', key: 'name', width: 40 },
    { header: 'SKU', key: 'sku', width: 16 },
    { header: '产品编号', key: 'code', width: 16 },
    { header: '单价', key: 'price', width: 10 },
    { header: '数量', key: 'qty', width: 8 },
    { header: '备注', key: 'note', width: 24 }
  ];

  // 5. 逐行写入数据和图片
  for (var r = 0; r < rows.length; r++) {
    var rowIdx = r + 2;
    var row = ws.getRow(rowIdx);
    row.height = 105;
    row.getCell(2).value = rows[r].name;
    row.getCell(3).value = rows[r].sku;
    row.getCell(4).value = rows[r].code;
    row.getCell(5).value = rows[r].price;
    row.getCell(6).value = rows[r].qty;
    row.getCell(7).value = rows[r].note;

    if (picBuffers[r] && picBuffers[r].buffer && picBuffers[r].buffer.byteLength > 0) {
      var buf = picBuffers[r].buffer;
      // 自动检测图片格式：JPEG以FF D8开头，PNG以89 50开头
      var ext = 'png';
      var u8 = new Uint8Array(buf);
      if (u8[0] === 0xFF && u8[1] === 0xD8) ext = 'jpeg';

      var imgId = wb.addImage({ buffer: buf, extension: ext });

      // 按原始尺寸等比缩放，适配单元格区域（最大140×105）
      var origW = picBuffers[r].width || 140;
      var origH = picBuffers[r].height || 140;
      var maxW = 140, maxH = 105;
      var scale = Math.min(maxW / origW, maxH / origH);
      var drawW = Math.round(origW * scale);
      var drawH = Math.round(origH * scale);

      ws.addImage(imgId, {
        tl: { col: 0, row: rowIdx - 1 },
        ext: { width: drawW, height: drawH }
      });
    }
  }

  // 6. 导出下载
  var outBuffer = await wb.xlsx.writeBuffer();
  var blob = new Blob([outBuffer], {
    type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
  });
  var a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = '产品明细_' + customerName + '_' + today + '.xlsx';
  a.click();
  URL.revokeObjectURL(a.href);
}

5. 踩坑总结

#问题原因解决
1 crossOrigin='anonymous' 导致图片加载失败 同源请求设crossOrigin后，浏览器不再自动带Cookie 同源图片不要设crossOrigin属性
2 Canvas toBlob 回调不触发，Promise挂起 跨域图片绘制后Canvas被"污染"，toBlob静默失败 放弃Canvas路线，改用fetch直接获取二进制
3 SheetJS社区版无法嵌入图片 社区版不支持addImage，Base64只能作为文本 换用ExcelJS（原生支持图片嵌入）
4 ExcelJS addImage传入Blob无效 addImage的buffer参数只接受ArrayBuffer fetch后调用resp.arrayBuffer()获取ArrayBuffer
5 fetch credentials:'include' 触发CORS错误 OSS返回 Allow-Origin:*，与credentials模式不兼容 使用fetch()默认模式（same-origin），不设credentials
6 图片URL中的&amp;导致fetch请求失败 服务器JSON返回的pic字段含HTML实体编码 getProductPicUrl中做HTML实体解码
7 缓存键类型不匹配导致图片查不到 row.id为数字，lookupId为字符串，对象键不一致 所有缓存操作统一用String(id)作为键
8 JPEG图片extension写png导致Excel打开异常 OSS返回的图片可能是JPEG格式 读取ArrayBuffer前2字节判断格式（FF D8=JPEG）
9 Excel中图片比例变形 ext固定写width:140, height:140，但原始图片不一定是正方形 获取原始尺寸后按Math.min(maxW/origW, maxH/origH)等比缩放

8. 注意事项

  1. fetch不要设credentials:'include' — OSS的CORS配置为通配符*，与include模式冲突
  2. 缓存键统一用String(id) — 服务器返回的id可能是数字，JS对象键会自动转字符串，但显式转换避免隐式问题
  3. HTML实体解码 — 服务器JSON返回的pic字段可能包含&amp;等HTML实体，fetch前必须解码
  4. 图片格式自动检测 — 读取ArrayBuffer前2字节：JPEG=FF D8，PNG=89 50，传给ExcelJS正确的extension
  5. 等比缩放防变形 — 用Math.min(maxW/origW, maxH/origH)计算缩放比，横图适配列宽、竖图适配行高，保证不变形
  6. 空值缓存防重 — 无图片的产品ID也写入空字符串缓存，避免每次导出都重复请求
  7. try/catch全局包裹 — 导出流程中任何环节报错都要showToast提示用户，不能静默失败
  8. 占位图兜底 — 图片获取失败时使用Canvas动态生成的占位图，保证Excel结构完整
最重要的一条 当图片URL涉及服务器302重定向到第三方存储（如阿里云OSS、腾讯COS）时，fetch(url) 使用默认模式即可。不要加 credentials:'include'，因为第三方存储的CORS通常配置为 Access-Control-Allow-Origin: *，与credentials模式不兼容。
