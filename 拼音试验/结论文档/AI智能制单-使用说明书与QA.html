📖 第一部分：使用说明书

一、系统概述

AI智能制单系统是一个智能制单工作台，帮助你快速将各种渠道的订单需求转化为标准制单。

🎯 核心价值：异构数据同构化

  • 无论订单来自微信文字、Excel文件、截图、电话语音，系统都能自动识别并匹配
  • 将杂乱、格式不一的订单需求，自动转换为业务系统要求的标准订单格式
  • 核心能力：拼音模糊匹配——同音不同字、错别字、生僻名称都能自动匹配

支持多渠道订单来源：

💬
微信文字
聊天记录中的订单信息
📊
Excel文件
表格形式的订单数据
🖼️
截图/图片
订单截图或照片
📞
电话语音
语音转文字后的订单
⚠️ 本系统是帮助销售人员快速做单录入的智能工作台，不是简单的语音录入工具，也不是边沟通边下单的工具。

二、系统准备

2.1 打开拼音数据管理工具

  • 操作：在制单页面点击"打开拼音工具"按钮
  • 目的：从业务系统同步客户和产品数据，生成拼音索引
⚠️ 首次使用必须先执行此步骤，否则无法进行客户和产品匹配。

2.2 全量同步数据

  • 点击"全量获取"按钮
  • 等待客户数据和产品数据依次获取完成
  • 点击"生成拼音"按钮，等待进度条完成
  • 同步时间显示为绿色表示数据就绪

2.3 日常增量同步

  • 每天上班后点击"增量获取"按钮
  • 系统自动拉取上次同步后新增/修改的数据
  • 拼音索引自动更新
💡 增量同步比全量同步快很多，日常使用推荐增量同步即可。

三、多渠道订单输入

3.1 方式一：Coze智能体对话（推荐）

  • 在"Coze智能体"面板中确认 Bot ID 和 Token 已填写
  • 点击"启动Coze"按钮，等待状态显示已连接 ✅
  • 右侧弹出智能体对话窗口
  • 用自然语言描述订单需求
  • 智能体返回结构化订单JSON后，复制JSON内容
💬 示例："我要给深圳研能科技下单，主板四核工控研能5块，排线PM1200 20米3根"

3.2 方式二：剪贴板粘贴

  • 直接将订单JSON复制到剪贴板
  • 系统自动检测剪贴板中的订单数据
  • 无需手动操作，复制即处理

3.3 方式三：手动添加

  • 点击"添加产品"按钮手动录入产品信息
  • 适合少量补充或修改的场景

四、订单匹配与确认

4.1 自动匹配流程

  • 系统自动进行客户匹配和产品匹配
  • 匹配结果展示在"单据草稿"区域

4.2 理解匹配状态

状态颜色含义操作
🟢 已确认 绿色 系统高置信度匹配 可直接使用，无需操作
🟡 待确认 黄色 找到候选但不确定 需要人工确认
🔴 未匹配 红色 未找到匹配项 需手动选择或新建

4.3 拼音匹配的典型场景

同音不同字
你说"华美"
→ 系统匹配 →
"华梅"
错别字纠正
输入"工空研能"
→ 系统匹配 →
"工控研能"
简称识别
输入"晨光A4"
→ 系统匹配 →
"晨光文具A4复印纸"
生僻型号
输入"ZSP4"
→ 系统匹配 →
对应产品

4.4 确认客户

  • 绿色"已确认"：无需操作
  • 黄色"待确认"：点击客户卡片查看候选列表，选择正确的客户
  • 未匹配：点击"搜索其他"手动查找

4.5 确认产品

  • 待确认产品：点击"确认"按钮确认，或点击"重新匹配"查看其他候选
  • 未匹配产品：点击"重新匹配"搜索，或点击"新建产品"录入
  • 可行内编辑：点击数量、单价、备注字段即可直接编辑

4.6 批量操作

  • 勾选多个产品后可批量确认或批量删除
  • "全部确认"按钮一键确认所有非错误产品

五、订单生成

  • 确认所有客户和产品后，点击"生成订单"按钮
  • 系统显示订单摘要（客户、产品数量、订单总额）
  • 点击"新建单据"可清空当前草稿，开始下一单
✅ 生成订单前请仔细核对客户信息和产品明细，确认无误后再提交。

七、支持的JSON格式

系统自动识别以下4种格式的订单JSON：

格式一（推荐）

{
  "customer_name": "客户名",
  "recv": "联系人",
  "addr": "地址",
  "products": [
    {
      "name": "品名",
      "model": "型号",
      "quantity": 10,
      "unit": "箱",
      "unit_price": 100,
      "specification": "规格"
    }
  ]
}

格式二（驼峰）

{
  "customerName": "客户名",
  "items": [
    {
      "name": "品名",
      "model": "型号",
      "quantity": 10
    }
  ]
}

格式三（中文键）

{
  "客户": "客户名",
  "产品": [
    {
      "品名": "品名",
      "型号": "型号",
      "数量": 10
    }
  ]
}

格式四（简写）

{
  "customer": "客户名",
  "products": [
    {
      "name": "品名",
      "model": "型号"
    }
  ]
}

❓ 第二部分：常见问题（QA）

Q 打开制单页面后显示"拼音数据未就绪"怎么办？

需要先打开拼音工具页面，执行全量数据同步和拼音生成。步骤：

  1. 点击"打开拼音工具"
  2. 点击"全量获取"
  3. 等待获取完成后点击"生成拼音"
  4. 返回制单页面，点击刷新按钮
Q 客户匹配不准确怎么办？
  • 点击客户卡片，在弹出的候选列表中选择正确的客户
  • 如果候选列表中没有，点击"搜索其他"手动输入搜索
  • 搜索支持拼音首字母和中文输入
Q 产品显示"待确认"黄色状态是什么意思？

系统找到了候选产品但置信度不够高，需要你确认是否正确。点击"确认"按钮确认，或点击"重新匹配"查看其他候选。

Q 同名产品怎么区分？

系统会自动根据型号和规格进行二次筛选：

  • 型号完全匹配 → 自动确认
  • 型号部分匹配 + 规格匹配 → 自动确认
  • 无法通过型号和规格唯一确定 → 标记待确认，需人工选择
Q 输入有错别字，系统能匹配到吗？

可以。系统使用拼音模糊匹配，即使输入有错别字（如"工空"匹配"工控"），只要拼音相近就能匹配。但如果错别字太多导致拼音差异过大，可能需要手动搜索。

Q 同音不同字的客户名怎么匹配？

系统基于拼音匹配，"华美"和"华梅"的拼音完全相同，系统会自动关联。如果存在多个同音客户，会标记为待确认，由你选择正确的那个。

Q 剪贴板监听不生效怎么办？
  • 确保浏览器已授权剪贴板读取权限
  • 确保页面有焦点（点击一下页面）
  • 尝试手动粘贴到结果区域
  • 检查复制的文本是否包含 customer_name、products 或 doc_type 关键字
Q Coze智能体连接失败怎么办？
  • 检查 Bot ID 和 Token 是否正确
  • 刷新页面重试
  • 检查网络连接
  • 如果持续失败，可跳过Coze，直接复制JSON到剪贴板
Q 如何不使用Coze，直接输入订单？

可以跳过Coze智能体，直接将订单JSON复制到剪贴板，系统会自动检测并匹配。也可以手动添加产品：点击"添加产品" → 填写产品信息。

Q 微信收到的文字订单怎么处理？

将微信中的订单信息通过Coze智能体转换为JSON格式，或手动整理为JSON后复制到剪贴板。系统会自动识别并匹配。

Q 单价和小计显示"-"怎么办？

说明JSON中没有提供价格信息。可以点击单价字段手动输入，小计会自动计算。

Q 修改数量或单价后小计没有更新？

小计会在输入框失焦或按 Enter 后自动更新。如果仍不更新，请刷新页面。

Q 数据同步后匹配结果没有变化？

制单页面会在窗口获得焦点时自动刷新拼音数据状态。如果没有自动刷新，请点击拼音数据面板的刷新按钮。

Q 如何处理JSON中缺少的产品？
  1. 点击"重新匹配"搜索产品库
  2. 如果产品库中确实没有，点击"新建产品"
  3. 填写产品名称、编号等信息，保存后自动关联
Q 增量同步和全量同步有什么区别？
  • 全量同步：拉取所有客户和产品数据，首次使用或数据异常时使用
  • 增量同步：仅拉取上次同步后新增/修改的数据，日常使用更快速
Q 匹配得分是怎么计算的？

系统使用四维评分算法：

维度权重说明
全拼相似度35%完整拼音的相似程度
首字母相似度25%拼音首字母的匹配程度
词袋余弦相似度30%关键词的覆盖程度
长度相似度10%名称长度的接近程度

判定标准：

  • 得分 ≥ 90% → 自动确认
  • 得分 70% ~ 90% → 待确认
  • 得分 < 70% → 未匹配
Q 联系人/收货地址字段不显示？

这两个字段来自JSON中的 recv 和 addr 字段。如果JSON中没有这两个字段，则不会显示。请确认智能体输出的JSON格式是否包含这些字段。

Q 如何在Coze对话中发送图片？

在Coze对话窗口中直接 Ctrl+V 粘贴图片即可。系统会自动将剪贴板中的图片注入到Coze的上传区域。

Q 删除产品后能恢复吗？

不能。删除操作需二次确认，请确认后再操作。如果误删，可以点击"添加产品"重新添加。

Q 浏览器兼容性要求？
  • 推荐使用 Chrome 90+ 或 Edge 90+
  • 需要支持 Clipboard API（剪贴板读取）
  • 需要支持 localStorage
  • 不支持 IE 浏览器
