基于扣子智能体 · 拼音+匹配结果混合输出

方案C：混合逻辑（对比基线）
智能体同时输出拼音和匹配结果，不区分"提取"和"匹配"两个步骤
接入真实扣子智能体 — 替换参数指南

三种方案对比

维度方案A：拼音输出方案B：知识库匹配方案C：混合逻辑
智能体返回仅拼音ID+标准名称拼音+匹配结果
匹配位置后端服务器智能体知识库未明确
交互步骤两步（提取→匹配）一步到位一步到位
企业适配通用，无需配置需每家企业配置知识库通用
匹配精度依赖后端算法知识库精确匹配模拟效果
适用场景SaaS通用大客户专属原型演示

前提条件

  • 在 coze.cn 创建智能体，配置好拼音输出Prompt
  • 在智能体发布页面，选择 Chat SDK 渠道并发布
  • 获取 botId（智能体编排页面URL中 bot/ 后的数字）
  • 生成 PAT令牌（个人访问令牌，用于调试；上线后改用OAuth）

需要替换的参数（共2个）

botId
智能体ID，在 coze.cn 智能体编排页面的URL中获取
https://www.coze.cn/space/xxx/bot/73428668**** → 取 73428668****
当前：模拟数据
token
访问令牌（PAT或OAuth），在 coze.cn 授权页面生成
调试用PAT，上线用OAuth
当前：无鉴权

替换步骤

Step 1：在 <head> 中添加扣子SDK脚本
<script src="https://lf-cdn.coze.cn/obj/unpkg/flow-platform/chat-app-sdk/1.2.0-beta.8/libs/cn/index.js"></script>
Step 2：找到右侧对话区的 <div class="chat-panel">，替换为以下代码
<script>
const cozeWebSDK = new CozeWebSDK.WebChatClient({
  config: {
    botId: 'YOUR_BOT_ID',  // ← 替换为你的智能体ID
    isIframe: false,
  },
  auth: {
    type: 'token',
    token: 'YOUR_PAT_TOKEN',  // ← 替换为你的PAT令牌
    onRefreshToken: async () => 'YOUR_PAT_TOKEN',
  },
  ui: {
    base: { lang: 'zh-CN' },
    asstBtn: { isNeed: false },
    chatBot: { position: { right: '20px', bottom: '20px' } }
  }
});
</script>
Step 3：删除右侧模拟对话区的全部HTML和JS代码
删除 <div class="chat-panel-wrapper">...</div> 整个区块
删除 JS 中所有 chat 相关函数（sendChatMessage, addChatBubble 等）
删除 chat 相关 CSS 样式

左侧单据草稿如何接收智能体结果

扣子智能体输出拼音后，需要通过后端API查询拼音索引并将匹配结果推送到左侧草稿区。两种方案：

  • 方案A（当前模式）：后端监听扣子对话结果 → 提取拼音字段 → 后端查询拼音索引 → 返回匹配结果 → 前端填充草稿
  • 方案B：扣子智能体配置知识库 → 智能体直接返回ID → 前端直接填充草稿（参见方案B原型）
